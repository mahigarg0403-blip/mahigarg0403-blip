## Featured Projects

### 🤖 [Helpdesk Agent: Multi-Tenant RAG SaaS](https://github.com/Mahi-Bhumika/helpdesk-agent)
Businesses embed an AI support chatbot trained only on their own PDF documentation.
- Zero cross-tenant data leakage using database-level **Row-Level Security**, validated with cross-tenant attack tests
- Custom ingestion pipeline with **ONNX-optimized MiniLM embeddings**, running within a 512MB memory limit
- Tenant-scoped **pgvector** search, with source attribution on every answer

`FastAPI` `Next.js` `Supabase` `pgvector` `ONNX Runtime` `Groq`

### 🛒 [E-Commerce Purchase Intention Prediction](https://github.com/Mahi-Bhumika/Customer-purchase-prediction_mahi_bhumika)
Compared Logistic Regression, Random Forest and XGBoost on 12,330 sessions (UCI Online Shoppers dataset).
- Best model: **Random Forest**, AUC 0.93, F1 0.68, accuracy 0.89
- SMOTE applied only on training splits to handle a 15.47% minority class without leakage
- SHAP explainability and an interactive Streamlit app

`Scikit-learn` `XGBoost` `SHAP` `SMOTE` `Streamlit`

### ✅ [FollowThrough](https://github.com/mahigarg0403-blip/FollowThrough)
An AI agent that turns messy meeting notes into owned tasks and keeps following up until they're done.
